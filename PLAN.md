# План приложения: PDF-ридер с рукописными заметками

Приложение для личного использования на планшете (Lenovo Xiaoxin Pad Pro 12.7, Android 16): открываем PDF с лекцией/книгой, читаем, к странице или фразе прикрепляем заметку — справа от текста открывается панель, где стилусом пишем заметку. Визуальный ориентир — Touch Notes.

## Требования (по ответам в QUESTIONS.md)

### PDF
- Импорт: выбор файла из памяти планшета; файл попадает в библиотеку
- Библиотека: список файлов; теги создаются из интерфейса; строка тегов над списком (горизонтальный скролл), фильтрация по тегам
- Поиск по тексту внутри PDF
- Сканы без текстового слоя: читать и ставить заметки можно, поиск по ним не нужен
- Без ограничений на размер файла

### Заметки
- Типы: текстовый комментарий, рукописный ввод (стилус/палец), highlight текста, маркер/стикер на странице
- Привязка: к странице и к выделенному тексту
- Индикаторы на страницах, где есть заметки
- У каждой заметки — поле TLDR (короткое описание) для поиска
- Список всех заметок документа с переходом к месту
- Хранение: отдельно от PDF, в своей БД (обоснование ниже)
- Автосохранение + история версий заметок

### Устройство и интерфейс
- Стилус + отсеивание ладони (palm rejection)
- Обе ориентации
- Режим разделённого экрана: PDF слева — панель заметок справа
- Язык: русский; темы: светлая/тёмная; стиль: минимализм
- Полностью офлайн, без аккаунта; данные локально
- Экспорт — не в MVP, но обновления приложения не должны терять данные

## Стек: Kotlin + Jetpack Compose (нативный Android)

Обоснование:

1. **Рукописный ввод — ядро приложения.** Нативный Android даёт прямой доступ к MotionEvent (давление, наклон, тип указателя) и встроенную классификацию стилус/ладонь — palm rejection работает «из коробки» через `TOOL_TYPE_STYLUS`/`TOOL_TYPE_PALM`. Библиотека `androidx.ink` (Jetpack Ink) даёт низколатентный рендеринг штрихов.
2. **PDF-рендеринг.** PdfRenderer встроен в Android; для больших файлов и лучшей производительности — Pdfium (используется в Chrome). Выделение текста и поиск — через PDF-библиотеку.
3. **Unity не подходит** — игровой движок: тяжёлый, слабая работа с текстом/PDF/системным UI, лишний вес.
4. **Flutter** — лишняя прослойка именно в критичных местах (стилус-латентность, PDF-движок через плагины, доступ к файловой системе). Для офлайн-приложения под одно устройство кроссплатформенность не нужна.
5. **Compose** — современный декларативный UI, хорошо ложится на «PDF + панель справа», темы и минималистичный дизайн.

Вспомогательные библиотеки: Room (БД заметок/тегов), Pdfium или PdfRenderer (рендер), androidx.ink (рукописный ввод), SAF/FilePicker (импорт).

### Хранение заметок — отдельная БД, не внутри PDF

- PDF-файл остаётся нетронутым; заметки — в Room (SQLite): страница, координаты, тип, штрихи (векторные), текст, TLDR
- Плюсы: не ломаем PDF, легко искать/фильтровать, история версий, экспорт потом любой формой
- Минус: заметки не видны в других ридерах — но экспорт в аннотированный PDF добавим позже

## MVP → далее

**MVP:**
1. Импорт PDF + библиотека (без тегов)
2. Просмотр PDF (листание, зум)
3. Рукописные заметки стилусом с привязкой к странице, панель справа
4. Сохранение (автосохранение) в Room

**Версия 2:**
- Теги и фильтрация библиотеки
- Поиск по тексту PDF и по TLDR заметок
- Highlight текста, текстовые комментарии, маркеры
- Список заметок документа, индикаторы страниц
- История версий

**Версия 3:**
- Экспорт (аннотированный PDF / заметки отдельно)
- Разделённый экран «чтение-заметки» (если не вошло в MVP)
- Полировка UI
