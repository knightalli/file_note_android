# Вопросы по приложению (PDF + заметки для Android-планшета)

Ответьте на вопросы в свободной форме — прямо под каждым вопросом или в конце файла. По ответам составим требования и план разработки.

## 1. Назначение и аудитория

1. Для кого приложение: только для себя, для учёбы/работы, или планируется публикация в Google Play?
2. Какой основной сценарий использования? (например: читаю лекцию в PDF и пишу конспект поверх / размечаю документы / учебник с пометками)
3. Есть ли приложения-референсы, которые нравятся? (Xodo, Samsung Notes, Flexcil, Squid, OneNote, Adobe Reader...)

## 2. Работа с PDF

4. Как PDF попадает в приложение?
   - выбор файла из памяти планшета
   - «открыть через / поделиться» из других приложений
   - импорт из облака (Google Drive, Dropbox)
   - другое?
5. Нужен ли просмотр списка всех PDF (библиотека)? Папки, теги, поиск, сортировка?
6. Нужен ли поиск по тексту внутри PDF?
7. Нужно ли работать со сканами без текстового слоя (только картинки)?
8. Ограничения на размер/длину PDF?

## 3. Заметки

9. Какие типы заметок нужны?
   - текстовый комментарий
   - рисование от руки (палец/стилус)
   - выделение текста (highlight), подчёркивание, зачёркивание
   - маркер/стикер на странице
   - аудиозаметка
   - фото/картинка
10. К чему привязывается заметка?
    - к странице в целом
    - к точке/области на странице
    - к выделенному тексту
11. Нужен ли список всех заметок по документу с переходом к месту?
12. Заметки сохраняются внутри PDF-файла (стандартные аннотации PDF) или отдельно в своём формате?
13. Нужен ли экспорт: PDF с заметками, заметки отдельным файлом, отправка другим людям?

## 4. Устройство и ввод

14. Какой планшет / минимальная версия Android?
15. Нужна ли поддержка стилуса (S Pen / USI / другой)? Отсеивание ладони (palm rejection)?
16. Ориентация экрана: только ландшафтная, только портретная, обе?
17. Нужен ли режим «читаю слева — заметки справа» (разделённый экран)?

## 5. Данные и синхронизация

18. Всё хранится локально или нужна синхронизация между устройствами / облачный бэкап?
19. Нужна ли авторизация (аккаунт) или приложение полностью офлайн?
20. Нужны ли автосохранение и история версий заметок?

## 6. Интерфейс

21. Язык интерфейса: только русский, английский, оба?
